# Ejercicio 2 (10 min): Implementar la interfaz acotada como agente principal

## Objetivo
Entrega tú mismo el cambio de interfaz completo más pequeño posible antes de las revisiones de los especialistas.

## Haz esto
Edita `/workshop/es/starter/app.js` y:
1. Mantén los componentes funcionales y enfocados.
2. Agrega o refina una sección ficticia de “Apoyo Comunitario”.
3. Mantén la nomenclatura accesible para principiantes y el contenido claramente ficticio/estático.
4. Evita ediciones no relacionadas y evita agregar dependencias.

## Resultado esperado
Una implementación pequeña, comprensible y acotada, lista para la retroalimentación de los especialistas.

## Criterios de aceptación
- [ ] El cambio de interfaz está completo pero es mínimo.
- [ ] Los componentes se mantienen pequeños y claros.
- [ ] No hay secretos, datos personales ni detalles de integración real.

## Punto de reflexión
¿Cómo mejoró la confianza y la capacidad de revisión al limitar el alcance?
