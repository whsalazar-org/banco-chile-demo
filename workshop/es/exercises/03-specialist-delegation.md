# Ejercicio 3 (9 min): Delegar en especialistas personalizados

## Objetivo
Practica decisiones y resultados realistas de delegación en especialistas.

## Haz esto
Usando tu `/workshop/es/starter/app.js` actualizado, registra qué le solicitarías a cada especialista:
1. **frontend-specialist**: una mejora de accesibilidad/usabilidad.
2. **test-specialist**: una estrategia práctica de validación para la configuración actual.
3. **security-reviewer**: una revisión enfocada de seguridad/gobernanza.
4. **documentation-specialist**: una mejora concisa de claridad para el taller/la entrega.

Para cada uno, incluye:
- Por qué este especialista (y no el agente principal solo)
- Resultado esperado (breve, accionable)
- Qué queda fuera del alcance

## Resultado esperado
Un mapa de delegación realista alineado con responsabilidades acotadas de los especialistas.

## Criterios de aceptación
- [ ] Existe una solicitud enfocada por cada especialista.
- [ ] Cada solicitud tiene límites de alcance claros.
- [ ] La delegación evita permisos amplios o innecesarios.

## Punto de reflexión
¿Qué especialista produjo la mayor reducción de riesgo y por qué?
