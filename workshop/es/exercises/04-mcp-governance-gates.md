# Ejercicio 4 (8 min): Decisiones de política MCP y puertas de aprobación

## Objetivo
Usa los documentos de catálogo/política de MCP para decidir qué está permitido, qué es de solo lectura y qué necesita aprobación.

## Haz esto
1. Revisa:
   - `/mcp/README.md`
   - `/mcp/policies/approved-tools.md`
2. En tus notas, clasifica estas acciones:
   - Leer metadatos del repositorio
   - Modificar el contenido del repositorio
   - Consultar datos similares a producción
   - Activar una operación destructiva
3. Para cada acción, indica:
   - ¿Permitida de forma predeterminada? (sí/no)
   - ¿Requiere aprobación humana? (sí/no)
   - Por qué, según el lenguaje de la política

## Resultado esperado
Puedes justificar las decisiones de MCP/herramientas usando la política del repositorio como fuente de verdad.

## Criterios de aceptación
- [ ] La tabla/lista de clasificación está completa.
- [ ] Las decisiones citan el privilegio mínimo y los valores predeterminados de solo lectura.
- [ ] Las puertas de aprobación se identifican correctamente para las acciones riesgosas.

## Punto de reflexión
¿Qué podría salir mal si un agente omite este paso de verificación de puertas?
