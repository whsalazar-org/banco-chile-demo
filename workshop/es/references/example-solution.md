# Resultado de referencia (enfocado en el escenario)

Usa esto como referencia de calidad para la estructura y la toma de decisiones.

## Forma sugerida de la implementación final

- Componentes funcionales pequeños en `starter/app.js`
- Una sección ficticia de "Apoyo Comunitario" agregada/refinada con nomenclatura accesible para principiantes
- Aviso claro de demo estática para evitar confusión con un servicio real

## Notas de validación (ejemplo)

- Se revisaron todos los archivos de `/workshop/es` en busca de secretos, tokens, contraseñas, cadenas de conexión y datos personales: no se encontró ninguno.
- Se confirmó que el taller sigue siendo ficticio/estático y no contiene orientación de integración de producción.
- Se confirmó que las referencias al uso de MCP están alineadas con la lista de aprobados y la política de privilegio mínimo.

## Notas de entrega (ejemplo)

- El agente principal entregó primero una actualización mínima y completa de la interfaz, y luego planificó el seguimiento con los especialistas.
- La solicitud al especialista de frontend se acotó únicamente al pulido de accesibilidad.
- La solicitud al especialista de pruebas se acotó a un enfoque práctico de validación para el entorno actual.
- La solicitud al revisor de seguridad se acotó a la alineación con la política y las verificaciones de operaciones riesgosas.
- La solicitud al especialista de documentación se acotó a mejoras concisas de claridad.

## Recordatorio de seguridad
Nunca uses datos bancarios/de clientes reales, credenciales u operaciones de producción en este taller.
