# Exercise 2 (12 min): Build focused UI components

## Objective
Extend the starter with small, focused functional components.

## Do this
Edit `/workshop/starter/app.js` and:
1. Keep components short and single-purpose (`Header`, `ServiceList`, `Notice`).
2. Add one extra presentational component named `HelpCard` with beginner-friendly labels.
3. Keep state local in `App` unless sharing is necessary.
4. Use accessible HTML (headings, list, readable text).

## Expected outcome
The page shows a simple fictional bank prototype with clear sections and readable content.

## Acceptance criteria
- [ ] Components are functional and focused.
- [ ] Naming is beginner-friendly.
- [ ] Changes are scoped to workshop files.
- [ ] UI text stays fictional and non-sensitive.

## Reflection checkpoint
How did small components make editing or understanding the page easier?
