# Exercise 2 (10 min): Implement scoped UI as primary agent

## Objective
Deliver the smallest complete UI change yourself before specialist reviews.

## Do this
Edit `/workshop/starter/app.js` and:
1. Keep components functional and focused.
2. Add or refine a fictional “Community Support” section.
3. Keep naming beginner-friendly and content clearly fictional/static.
4. Avoid unrelated edits and avoid adding dependencies.

## Expected outcome
A small, understandable, scoped implementation ready for specialist feedback.

## Acceptance criteria
- [ ] UI change is complete but minimal.
- [ ] Components remain small and clear.
- [ ] No secrets, personal data, or real integration details.

## Reflection checkpoint
How did limiting scope improve confidence and reviewability?
