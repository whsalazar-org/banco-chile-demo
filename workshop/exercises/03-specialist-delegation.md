# Exercise 3 (9 min): Delegate to custom specialists

## Objective
Practice realistic specialist delegation decisions and outputs.

## Do this
Using your updated `/workshop/starter/app.js`, record what you would request from each specialist:
1. **frontend-specialist**: one accessibility/usability refinement.
2. **test-specialist**: one practical validation strategy for current setup.
3. **security-reviewer**: one focused security/governance pass.
4. **documentation-specialist**: one concise workshop/handoff clarity improvement.

For each, include:
- Why this specialist (not primary agent alone)
- Expected output (short, actionable)
- What stays out of scope

## Expected outcome
A realistic delegation map aligned with bounded specialist responsibilities.

## Acceptance criteria
- [ ] One focused request per specialist exists.
- [ ] Each request has clear scope boundaries.
- [ ] Delegation avoids broad or unnecessary permissions.

## Reflection checkpoint
Which specialist produced the highest risk reduction and why?
