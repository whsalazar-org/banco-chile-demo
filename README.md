# banco-chile-demo

This repository is an example of a Copilot-ready structure.

## Copilot file structure

- `.github/copilot-instructions.md` - repository-wide Copilot instructions.
- `.github/instructions/react-webapp.instructions.md` - path-specific custom instructions for React + JavaScript web app files.
- `.github/skills/react-simple-webapp/SKILL.md` - reusable skill guidance for building a simple React app.
- `.github/agents/react-webapp.agent.md` - custom agent definition for React + JavaScript web app tasks.

## Current focus

Instructions in this repository are currently tailored to creating a simple web application with React and JavaScript.
